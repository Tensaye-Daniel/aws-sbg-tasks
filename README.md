## About

This repository contains practical coding exercises and assignments completed
throughout my learning journey. Each task provides an opportunity to explore
programming concepts, apply theoretical knowledge, and develop a deeper
understanding through hands-on experience.

Every weekly task is submitted in its own folder and contains both the source
code (`.py`) and the Google Colab notebook (`.ipynb`) with outputs and
explanations.
